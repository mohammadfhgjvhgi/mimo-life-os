# Smart Parking System API Documentation

## Overview

This document describes the API for the Smart Parking System, which includes hardware interfaces, Firebase database structure, and web dashboard endpoints.

## Hardware Interfaces

### Arduino Mega to ESP8266 Communication Protocol

The Arduino Mega sends status updates to the ESP8266 using a simple text protocol:

**Message Format**: `SPOT:spot_number,status`

**Example**: `SPOT:1,1` (Spot 1 is occupied)

**Parameters**:
- `spot_number`: Integer (1-4) representing the parking spot number
- `status`: Integer (0 = vacant, 1 = occupied)
