# Smart Parking System Setup Guide

## Hardware Setup

### Components Needed
1. Arduino Mega
2. ESP8266 WiFi Module
3. 4x HC-SR04 Ultrasonic Sensors
4. 4x LEDs (Red/Green)
5. 4x 220Ω Resistors
6. Breadboard
7. Jumper wires

### Wiring Instructions

#### Arduino Mega Connections
- **Ultrasonic Sensors**:
  - Sensor 1: Trig -> Pin 22, Echo -> Pin 23
  - Sensor 2: Trig -> Pin 24, Echo -> Pin 25
  - Sensor 3: Trig -> Pin 26, Echo -> Pin 27
  - Sensor 4: Trig -> Pin 28, Echo -> Pin 29

- **LEDs**:
  - LED 1: Anode -> Pin 30 (via 220Ω resistor), Cathode -> GND
  - LED 2: Anode -> Pin 32 (via 220Ω resistor), Cathode -> GND
  - LED 3: Anode -> Pin 34 (via 220Ω resistor), Cathode -> GND
  - LED 4: Anode -> Pin 36 (via 220Ω resistor), Cathode -> GND

- **ESP8266 Communication**:
  - ESP8266 TX -> Arduino Pin 2 (RX)
  - ESP8266 RX -> Arduino Pin 3 (TX)
  - ESP8266 VCC -> Arduino 5V
  - ESP8266 GND -> Arduino GND

#### ESP8266 Connections
- **Power**:
  - VCC -> 3.3V (Note: Some ESP8266 modules require 3.3V, check your module specifications)
  - GND -> GND

- **WiFi Antenna**: Ensure the antenna is properly connected

## Software Setup

### Arduino Mega
1. Install Arduino IDE if not already installed
2. Connect Arduino Mega to your computer via USB
3. Open `hardware/arduino-mega/parking_sensor.ino` in Arduino IDE
4. Update the pin definitions if needed
5. Upload the sketch to Arduino Mega

### ESP8266
1. Install ESP8266 board support in Arduino IDE:
   - File > Preferences > Additional Boards Manager URLs: 
     `http://arduino.esp8266.com/stable/package_esp8266com_index.json`
   - Tools > Board > Boards Manager > Search for "esp8266" and install
2. Select the correct board: Tools > Board > ESP8266 Boards > NodeMCU 1.0 (ESP-12E Module)
3. Open `hardware/esp8266/wifi_communication.ino` in Arduino IDE
4. Update WiFi credentials and Firebase configuration
5. Upload the sketch to ESP8266

### Firebase Setup
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create a new project
3. Enable Realtime Database:
   - Database > Create Database > Start in test mode
4. Add rules to allow read/write:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
5. Get your Firebase configuration details:
   - Project settings > Your apps > Web app
   - Note the API key, authDomain, databaseURL, etc.

### Web Dashboard Setup
1. Create a new Next.js project:
   ```bash
   npx create-next-app smart-parking-dashboard
   cd smart-parking-dashboard
   ```
2. Install Firebase:
   ```bash
   npm install firebase
   ```
3. Create the configuration and database files as shown above
4. Create the ParkingDashboard component
5. Run the development server:
   ```bash
   npm run dev
   ```

## Testing the System

1. Power on the Arduino Mega and ESP8266
2. Check the serial monitor for connection status
3. Verify that the LEDs change based on object detection
4. Open the web dashboard and check if the parking spots update in real-time

## Troubleshooting

### Common Issues

1. **WiFi Connection Issues**:
   - Verify WiFi credentials in ESP8266 code
   - Ensure the ESP8266 is within range of the WiFi network
   - Check if the ESP8266 is properly powered

2. **Firebase Connection Issues**:
   - Verify Firebase configuration details
   - Check if the database rules allow read/write access
   - Ensure the device has internet connectivity

3. **Sensor Issues**:
   - Check wiring connections
   - Verify the sensors are powered correctly
   - Test each sensor individually with a simple sketch

4. **Web Dashboard Issues**:
   - Verify Firebase configuration in the web app
   - Check browser console for errors
   - Ensure the database path matches the code
