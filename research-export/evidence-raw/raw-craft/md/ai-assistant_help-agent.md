# Help Agent

> Get instant answers about Craft features without leaving the app or breaking your workflow.

The Help Agent makes it easy to get answers about Craft without breaking your workflow. Instead of opening a browser, searching through help articles, and switching between tabs, you can ask questions directly inside Craft and get instant, accurate guidance.

<iframe src="https://www.youtube-nocookie.com/embed/o_07YXNtdhU" title="Help Agent overview video" className="w-full aspect-video rounded-xl" allowFullScreen />

## Why the Help Agent matters

When you're working, even a small interruption can pull you out of focus. A simple question like "Can I link items in a collection to other documents?" might take several minutes to solve if you have to search for documentation.

These context switches add up, especially if you're learning Craft, exploring new features, or onboarding to a team workspace.

The Help Agent removes that friction. It gives you quick, reliable answers in seconds, right inside the app.

## Opening the Help Agent

You can bring up the Help Agent at any time:

<Steps>
  <Step>
    Click the Assistant icon in the bottom right corner of the Craft interface.
  </Step>

  <Step>
    Select **New Chat**.
  </Step>

  <Step>
    Choose **Help and Support**.
  </Step>
</Steps>

## Example: Linking collection items

Imagine Marcus, a freelance designer setting up a collection to track project deliverables. He wants to link items in the collection to other documents but isn't sure if this is possible.

Instead of stopping to search online, Marcus opens the Help Agent and asks:

**"Can I link collection items to other documents?"**

The Help Agent instantly replies:

* Yes, it's possible using relations.
* It explains how to set them up.
* It takes about 20 seconds.

Marcus keeps working without leaving Craft or losing focus.

## When to use the Help Agent

Use the Help Agent whenever you need quick clarity, such as:

* Learning Craft for the first time
* Checking whether a feature exists
* Figuring out how to use a specific tool
* Troubleshooting unexpected behavior
* Supporting team onboarding
* Understanding plan differences or billing

Instead of breaking your flow, you get an immediate and actionable answer.

## Help Agent vs. regular Assistant

| Feature      | Help Agent                   | Regular Assistant                     |
| ------------ | ---------------------------- | ------------------------------------- |
| **Purpose**  | Answers about Craft features | Works with your content               |
| **AI usage** | Free                         | Uses your AI quota (except on-device) |
| **Context**  | Craft documentation          | Your documents and spaces             |
| **Best for** | Learning and troubleshooting | Content analysis and creation         |

Use the **Help Agent** for questions about Craft itself. Use the **regular Assistant** for questions about your content, summaries, and document work.

## Stay in flow

The Help Agent is designed to keep you focused on your work. No browser tabs. No searching. No context switching. Just fast, precise help right when you need it.

Craft handles the guidance so you can keep creating.
