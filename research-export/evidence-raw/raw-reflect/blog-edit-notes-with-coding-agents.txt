This new functionality unlocks a ton of new workflows if you use coding agents. 🏗️ Product Updates • Published on Apr 28, 2026 Alex MacCaw Founder and CEO of Reflect Table of Contents Editing notes through Reflect's MCP Table of Contents Editing notes through Reflect's MCP Twitter Facebook LinkedIn Last month we added MCP support that lets AI coding agents like Claude Code, Cursor, and Codex connect directly to Reflect. We've expanded this functionality to let you edit your notes through these coding agents as well.This new functionality unlocks a ton of new workflows if you use coding agents. You can do things like automatically update Reflect notes about the project you're working on, edit your notes in bulk, and a lot more.Read more below on the elements you can edit and some starting workflows to try. Editing notes through Reflect's MCP If you haven't yet set up the MCP for Reflect, head to this page on Reflect Academy for simple setup instructions. Coding agents can now: Add content — append to your daily note, or insert at the top, bottom, or a specific spot in any note Edit content — replace a range of lines, or rewrite text inside a single block Delete content — remove a range of lines in one call Rename a note — update a note's title Toggle a checkbox — check or uncheck a task Restyle a block — change heading level, list kind (bullet / ordered / task / checklist), collapsed state, or code block language Try asking your coding agent to: Append today's standup notes to your daily note the moment the meeting ends Have your coding agent log what it just shipped into your project's running notes Update a contact's details in your notes without opening the app and hunting around Auto-tick items in your release checklist as each deploy step finishes Convert a brain-dump bullet list into a checklist before sprint planning Clean out all your finished tasks from a project list in one sweep We are still exploring the possibilities of these new MCP capabilities ourselves. If you come across a use-case you'd like to share, drop a note in the #workflows channel within our Discord !
