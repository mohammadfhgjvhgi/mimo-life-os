Reflect Update:  MCP support for coding agents

Reflect notes now has an MCP server to access and search your notes directly from within Claude and Codex.

We've added an MCP server to access and search your notes directly from within Claude and Codex. Find out how to set up and use it below.

Setting up and using the MCP server

We've added setup information to this page on Reflect Academy. It walks you through how to install the MCP server via the terminal.
If you're not comfortable using your terminal, the academy page also has a setup guide that you can download and upload into your preferred coding agent and it will walk you through the setup. We have a walkthrough video of this here.
Once setup, your coding agent will be able to access and retrieve any information in your notes.
We've received a ton of requests for this MCP support in Reflect, so we hope you enjoy it!
