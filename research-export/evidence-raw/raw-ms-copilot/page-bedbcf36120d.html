Overview of Microsoft 365 Copilot Chat

In this article

Microsoft 365 Copilot Chat (Copilot Chat)

Microsoft 365 Copilot Chat offers secure, AI chat that adds pay-as-you-go agents. Copilot Chat includes:

  • Secure, AI chat grounded in the web and powered by the latest models
  • A side-by-side experience that's aware of a user's open content in select Microsoft 365 apps like Teams and Outlook
  • Pay-as-you-go agents accessible from chat, priced on a metered basis
  • IT controls, enterprise data protection, and agent management
  • Features like Copilot Pages, file upload, and image generation

Whether researching industry insights, analyzing data, or looking for inspiration, Copilot Chat gives users access to better answers, greater efficiency, and new ways to get their work done through chat and agents.

Note

Copilot Chat includes standard access to capabilities like file upload, image generation, and models (like GPT-5). This means it's subject to service capacity availability to ensure the product works well for everyone. Quality and performance may also vary depending on service availability. If the service isn't available at a given moment, Copilot notifies the user—it doesn't interrupt a task in progress.

If you'd like to enable users with priority access to these capabilities, learn how to upgrade to Microsoft 365 Copilot.

Copilot Chat adheres to Microsoft's Responsible AI principles. Learn more about Responsible AI at Microsoft.

Using Copilot Chat doesn't require a Microsoft 365 Copilot license. For more information, visit Microsoft 365 Copilot Chat eligibility.

The Copilot Chat user interface for work and education

Microsoft 365 Copilot Chat offers a UI designed for work and education. Users know they're protected by the green shield in the top right of the UI. Users can access agents, Copilot Search, and their recent chats from the left panel. Additionally, suggested prompts in the center of the UI can help users get started.

Enterprise data protection

Microsoft 365 Copilot Chat offers enterprise data protection (EDP). Get more details on privacy and protections in Copilot Chat.

Differences between Copilot Chat and Microsoft 365 Copilot

Copilot Chat is AI chat grounded in data from the web and powered by the latest large language models (LLMs). Copilot Chat lets users access agents and create them in the Microsoft 365 Copilot app. Additionally, they can use features like Copilot Pages, file upload, and image generation.

Unlike Microsoft 365 Copilot, Copilot Chat is not grounded in organizational content like files, emails, or chats as part of the chat experience—it is grounded in data from the web only. If Copilot Chat users would like to use organizational content in their chat, they can do so in three ways:

  • As part of their prompt (such as copying and pasting in content, uploading a file using the '+' button, including a file by typing '/' and selecting it from the ContextIQ menu, or selecting a suggested prompt which contains a file).
  • By using Copilot Chat in select Microsoft 365 apps like Teams and Outlook with content they have open. In this scenario, Copilot Chat is aware of the user's open content and is able to engage with it instead of requiring the user to upload a file or copy and paste the content into Copilot Chat.
  • By using a pay-as-you-go agent that has access to organizational content.

A paid license for Microsoft 365 Copilot includes Copilot Chat plus other Copilot value for users and admins. Microsoft 365 Copilot includes additional value like:

  • Chat grounded in work sources (files, meetings, emails, and chats) and priority access to capabilities like file upload and image generation, and reasoning capabilities and models (like GPT-5)
  • Integration in Microsoft 365 Copilot apps like Teams, Outlook, Word, Excel, PowerPoint, and more, with advanced skills and in-app editing
  • Comprehensive access to agents, including Analyst & Researcher advanced reasoning agents, prebuilt Microsoft agents, and custom agents grounded in your data
  • Additional Copilot Control System value like SharePoint Advanced Management and Copilot Analytics.

Where to access Copilot Chat

Users can access Copilot Chat from:

  • Web: m365copilot.com
    • Users with Copilot Chat pinned in the Microsoft 365 Copilot app are redirected to m365.cloud.microsoft/chat. Users who don't have Copilot Chat pinned can still access chat in a temporary state at m365.cloud.microsoft/chat, though it will remain unpinned unless the user actively pins it. Get more details on how to pin Copilot Chat.
  • Browser sidepane: Copilot in Microsoft Edge (web browser only)
  • Apps:
    • Microsoft 365 Copilot app (web, Windows, Mac, mobile)
    • Outlook (web, Windows, Mac, mobile)
      • Full pane (left nav) and side pane
    • Teams (web, Windows, Mac, mobile)
      • Full pane (left nav)
  • Agents:
    • Word, Excel, and PowerPoint agents in the Microsoft 365 Copilot app (web, Windows, Mac, mobile)

Note

Copilot experiences in Word, Excel, PowerPoint, and OneNote may vary depending on your organization's licensing and tenant configuration. In-product labels are displayed in Microsoft 365 apps like Word, Excel, PowerPoint, and OneNote, and in the Microsoft 365 Copilot app, to help users identify their Copilot experience.

M365 Copilot (Premium) indicates that a user has a Microsoft 365 Copilot add-on license and the full experience and priority access for Copilot chat in Word, Excel, PowerPoint, and OneNote.

M365 Copilot (Basic) indicates that a user does not have the Microsoft 365 Copilot add-on license but will have standard access to Copilot in those apps to ensure a reliable experience.

Copilot Chat (Basic) indicates that a user does not have the Microsoft 365 Copilot add-on license and does not have access to Copilot chat in Word, Excel, PowerPoint and OneNote.

If you'd like to enable users with priority access to these capabilities, learn more about the add-on license for Microsoft 365 Copilot.

Model selection in Copilot Chat

Copilot Chat offers the latest models tailored to your business needs without changing your security, compliance, and privacy settings. Users can select different models using the model selector at the top right of the UI. By default, Copilot uses a real-time router to adjust the underlying model it uses based on your prompt.

  • Quick response: For common or routine questions, Copilot prioritizes speed, using a high-throughput model to craft quick, succinct responses to straightforward questions.
  • Think deeper: For complex or more open-ended questions, Copilot may detect that the prompt requires advanced reasoning. In these cases, Copilot uses a deeper reasoning model, taking its time to craft a plan, gather and comprehend all relevant context, and check its work before providing a thorough response.

Based on the nature of a user's question, Copilot determines which model to use while in the default "Auto" mode. Users can set Copilot to use either "Quick response" or "Think deeper" by clicking the toggle at the top right of the UI where "Auto" is preselected. These options will update as new models become available.
