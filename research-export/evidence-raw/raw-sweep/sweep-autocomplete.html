Next-Edit Autocomplete

Next Edit / Tab Autocomplete

Sweep supports next-edit prediction inside JetBrains. Our autocomplete keeps track of what you're doing and automatically suggests the next edit you want to make.

You can also press tab to jump from your current location to the suggested next location, making repetitive code changes seamless.

This feature is enabled by default. If you are on JetBrains Gateway, please follow the instructions for JetBrains Gateway.

Keyboard shortcuts

You can change the keyboard shortcuts via the keymap (Settings > Keymap).

  1. Accept Autocomplete Suggestion: Default Tab. This will accept the next edit suggestion.
  2. Reject Autocomplete Suggestion: Default Esc. This will reject the next edit suggestion.
  3. Show Last Rejected Suggestion: Default option shift backspace (Mac) / alt shift backspace (Windows). This is like an "undo" button when you've accidentally rejected a suggestion and want to see it again.

Please email team@sweep.dev or join our discord (opens in a new tab) for any feature requests!
