AI Code Review

Sweep can review your code changes for potential bugs and issues before you commit.

How to Use

  1. Open the JetBrains search menu (shift shift)
  2. Search for "AI Code Review"

  1. Sweep will open a review panel showing your changes and a prompt to review them.

  1. Press Enter or click the send button to start the review

Sweep will read the relevant changes and their dependencies to provide feedback on potential issues, bugs, or improvements.
