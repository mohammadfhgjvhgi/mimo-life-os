# Start a project

> Start a new Bolt project from a blank prompt, uploaded files, a Figma or Google Stitch design, or a team template.

You can start a new project on the [Bolt homepage](https://bolt.new). Anyone can start from a blank prompt, upload files to build with, or import designs from Figma or Google Stitch. If you're on a team, you can also start from a template your team has saved for reuse.

## Before you build

Taking a few minutes to set up before you start can save significant rework later.

* **[Choose an agent](/building/using-bolt/agents).** Bolt offers two agents with different strengths. The Standard agent is suited to most development tasks and is available on all plans. The Max agent has deeper reasoning for complex tasks and requires a paid plan.
* **[Enhance your prompt](/best-practices/prompting-effectively#automatically-improve-your-prompt).** Get more accurate output by letting Bolt help you refine your prompt before you build. This lets Bolt ask you clarifying questions if it needs more information to get started.
* **[Use Plan mode](/best-practices/plan-mode).** Chat with Bolt to build a plan before Bolt starts generating code. Review the plan first to make sure Bolt understands what you want to build.
* **[Start with your design system](/building/design-system/use-design-system#start-a-project-with-a-design-system).** If you're on a Teams plan and have a design system set up, select it before sending your first prompt. Starting with your design system helps Bolt build consistently with your code, rather than having to refactor later to use your design system components.

## Start from a blank prompt

From the Bolt homepage, type what you want to build in the chatbox and press **Enter**. Bolt creates a new project and begins building.

<Info>
  From the Projects page, click **Create project** to return to the Bolt homepage and start building.
</Info>

## Start from a Bolt marketplace template

The [Bolt Templates marketplace](https://bolt.new/resources/templates) has working projects you can customize and publish. Using a template is free to start. When you customize it, you spend [tokens](/account-and-subscription/tokens) from your account the same way you do on any other project.

Templates in the marketplace include more than a design. Each one has real data and working features, so you don't have to build everything yourself. The marketplace includes templates for different use cases, like websites, apps, and internal tools.

To start from a Bolt marketplace template:

1. Go to the [template marketplace](https://bolt.new/resources/templates).
2. Browse or search for a template.
3. (Optional) To view and interact with the template before using it, click **Preview**.
4. To copy the template and open it as a new project in your workspace, click **Use template**.

<Info>
  Your copy of the project isn't tied to the template. If the template changes later, your project won't be affected.
</Info>

## Upload files

You can upload files to add to your project or to give Bolt context for what you want to build. Tell Bolt how to use the file in your prompt, or let Bolt detect it automatically.

To get started, see [Attach files to your project](/building/upload-files).

## Import a Figma frame

[Figma](https://figma.com) is a design tool for creating app and website mockups. You can import a Figma frame into Bolt to generate a project based on your design, or use it as a reference in an existing project.

To get started, see [Figma for design](/integrations/figma).

## Import a Google Stitch design

[Google Stitch](https://stitch.withgoogle.com) is an AI-powered design tool that generates app mockups and design systems from prompts. When your designs are ready, you can import them into Bolt to build out your app.

To get started, see [Use Google Stitch designs in Bolt](/integrations/google-stitch).

## Start from an existing project

If you're migrating an existing project from GitHub or Lovable rather than starting from scratch, see [Import an existing repository](/integrations/git) or [Import from Lovable](/integrations/lovable-import).

## Start from a team template

<Note>
  Team templates are available on [Teams plans](/account-and-subscription/team-plans) only.
</Note>

Team templates are reusable projects your team creates and shares. Each template can include files, configuration, and structure. When you start from one, Bolt creates a new project based on it. The original template stays unchanged.

To get started, see [Team templates](/account-and-subscription/teams/team-templates#open-a-team-template-from-the-homepage).
