Oct 2022 Research Prototype

Incremental CodeQL

The goal of the Incremental CodeQL project is to investigate the potential for incrementalization to improve the performance of CodeQL query evaluation. Instead of having to re-analyze the whole code base from scratch, incremental evaluation reuses the previously computed analysis results and only re-analyzes the parts of the code base that are affected by a program change. This approach can lead to significant performance speed-ups without the need to make any changes to the analysis implementation.
