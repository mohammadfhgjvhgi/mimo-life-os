# Objects

In Anytype, everything you create is an Object. A page, task, project, person, image, recipe—all are Objects. If you've used other tools, you might be used to thinking in terms of files and folders in a tree-like hierarchy. But this is not how Anytype works.

* **Folders ask "where does this go?"** You must decide if your note falls under the folder Meetings, Clients, or Projects. If you want it in more than one, you have to duplicate your note.
* **Objects ask "what does this relate to?"** — Your note exists by itself and you can connect it to your Meetings, Clients, and Projects all at the same time. No duplication.

With Anytype, you create an Object and add relationships over time. This builds a flexible system of interconnected knowledge that doesn't care where something is, just cares what it's related to.

## Why it matters

Because everything is an Object, everything can connect to everything else. A task can link to a person. A meeting note can link to a project. You're building a graph of interconnected information, rather than sorting files into folder hierarchies.

This means:

* **Everything is easy to find.** A single person can be connected to a company, a project, a meeting, a task, and more—so you can reach them from any of those angles.
* **No duplicates.** Link the same image to multiple documents instead of copying it into each one.
* **Start with creation, not organization.** You never have to decide whether a note belongs under "Work" or "Personal"—it can be both at once.
* **Patterns emerge over time.** As you add more links, connections you didn't plan for start to surface on their own that can reveal insights.

## How it works

Every Object has:

* [Types](/anytype/organize/types.md) that categorizes what kind of thing it is, such as Note, Task, Project, Meeting, etc.
* [Properties](/anytype/organize/properties.md) that hold its details, such as status, date, author, email, etc.
* [Links](/anytype/create/links.md) to other Objects, such as a Recipe connected to a Person.

Here is a simple example of how this works:

1. You create a **Task**, which is a Type.
2. You add a **due date**, which is a Property.
3. You connect it to a **Project**, which is a Link.

## Create Objects

#### Create Menu

Located at the top of the Sidebar next to the Channel name, is your main creation button used to get content into your space. There are two parts to the button:

* **Create Button** — when clicking the 'Create' button, you’ll immediately create a new Object. The default [Type](/anytype/organize/types.md) that is used for your Objects is set from your [Channel Settings](/anytype/settings/channel-settings.md)—by default it is 'Page'.
* **Create Dropdown** — when clicking the 'Create Dropdown' button, the downward arrow on the right, you'll be presented with a menu:
  * Types that you'd like to create an Object straight into.
  * Create from clipboard
  * Upload from computer

<div data-with-frame="true"><figure><img src="/files/hWck8Ve6FraBlWY32gey" alt=""><figcaption></figcaption></figure></div>

#### Types Section

You can create an Object directly from the Types section of the Sidebar by hovering over the [Type](/anytype/organize/types.md) and clicking on the 'plus' button. Here you will also find Queries and Collections. Please note:

* If this section is not showing, please see [Manage Sections](/anytype/basics/sidebar/sections.md#manage-sections) to reveal it.
* Only Types with at least one Object in them will display in this section. If your desired category is not in the Types section, [use the create menu](#create-menu) to create one object first, then it will reveal in this section.

<div data-with-frame="true"><figure><img src="/files/G3D6Opio7U0S0YiJhA8G" alt=""><figcaption></figcaption></figure></div>

#### Command Menu

When working in the editor you can type `/` to bring up the command menu. If you already know which Type you want to use, you can just type it directly. If you're not sure which Type you want to use, you can scroll to the 'Types' section to choose.

Objects created this way will leave a block link on the page and set a [backlink](/anytype/create/links.md) to the newly created object.

<div data-with-frame="true"><figure><img src="/files/se5LUW7AXtFDnQHMEiS1" alt=""><figcaption></figcaption></figure></div>

#### Use a Shortcut

For a quick creation of a new Object, you can use this shortcut: `Cmd/Ctrl + N` —this will perform the same action as clicking the "+" sign in the sidebar. Additionally, you can use `Cmd/Ctrl + Opt/Alt + N` to perform the same action as clicking the arrow sign in the sidebar.

#### Turn Into Object

If you are working on an existing Object and would like to transform only a certain block into an Object, you can do that through the action menu by:

1. Hovering to the left side of the block that you are working on and clicking the 3 dots.
2. Click **Turn into object** and select your desired [Type](/anytype/organize/types.md).

<div data-with-frame="true"><figure><img src="/files/GQGTYLMKa6CjYsGhRQQQ" alt=""><figcaption></figcaption></figure></div>

## Locating Your Objects

#### Sidebar

You can now find all your objects in the [Sidebar](/anytype/basics/sidebar.md), grouped by their respective [Types](/anytype/organize/types.md). If this section is not showing, please see [Manage Sections](/anytype/basics/sidebar/sections.md#manage-sections) to reveal it.

<div data-with-frame="true"><figure><img src="/files/rnYEof3ymdi94PAZRDtM" alt=""><figcaption></figcaption></figure></div>

#### Search

To navigate to the search, you can:

* Head to your sidebar and click on the search button.
* Use the `Cmd / Ctrl + K` keyboard shortcut.

<div data-with-frame="true"><figure><img src="/files/kLqtdhCgK0dpFA08roEU" alt=""><figcaption></figcaption></figure></div>

#### Graph

To find all of your objects and how they are connected, you can look to the [Graph](/anytype/features/graph.md) for your main source of truth. When viewing an Object, click on the 'Graph' icon that is located near the back and forward buttons.

<div data-with-frame="true"><figure><img src="/files/vFCWtubBpC5DSvRQUeUp" alt=""><figcaption></figcaption></figure></div>

#### Bin

If you've previously removed some objects from your [Channels](/anytype/basics/channels.md), they will appear in your [Bin](/anytype/organize/deletion.md) unless you've already permanently deleted them.

You can access your Bin from the Sidebar. If this section is not showing, please see [Manage Sections](/anytype/basics/sidebar/sections.md#manage-sections) to reveal it.

## Bulk editing Objects

Objects have Types and Properties which are best visualized in [Views](/anytype/organize/views.md). To edit multiple objects at the same time, the best approach is to use the Views feature—[see more here](/anytype/organize/views.md#bulk-editing-objects).

## Set Default Object

To choose which Type is used when creating an Object by default:

1. Click on the Create Dropdown arrow in the Sidebar
2. Hover over your desired Type
3. Click on the 'three dots' button
4. Select the option **Set as default**.

Alternatively you can set this in the [Channel Settings](/anytype/settings/channel-settings.md).

<div data-with-frame="true"><figure><img src="/files/ghSbeYyutmwFHT1StGyr" alt=""><figcaption></figcaption></figure></div>

## Tips

{% hint style="info" %}
**Use Views to make sense of your Objects.** Because there is no folder hierarchy for Objects, the best way to stay organized is to use [Views](/anytype/organize/views.md).
{% endhint %}
