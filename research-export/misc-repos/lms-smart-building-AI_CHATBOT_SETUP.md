# ملخص إعدادات المساعد الذكي (AI Chatbot) - LMS

## 📋 نظرة عامة
تم تطوير نظام مساعد ذكي متخصص لمادة "تكنولوجيا المباني الذكية" للصف الثاني عشر الصناعي.

---

## 🔧 المكونات التقنية

### 1. API Route (`app/api/chat/route.ts`)

#### المحرك الأساسي:
- **مزود الخدمة**: Groq API
- **النموذج**: Llama 3.1 8B Instant
- **مفتاح API**: `GROQ_API_KEY` (مخزن في `.env`)
- **Timeout**: 4-6 ثوانٍ للإجابات

#### الميزات:
1. **الردود المؤكدة فقط**: System Prompt صارم يمنع الإجابات الخاطئة
2. **البحث عن الأسئلة المعقدة**: كشف تلقائي للأسئلة التي تحتاج بحث
3. **تحليل الصور**: دعم رفع الصور للتحليل (مع fallback)
4. **نظام Fallback محلي**: قاعدة بيانات داخلية للإجابات السريعة

#### المواضيع المدعومة:
- CCTV (DVR, NVR, أنواع الكاميرات)
- أنظمة إنذار الحريق (كواشف، لوحات تحكم)
- أنظمة إنذار السرقة (PIR, Magnetic Contact)
- التحكم بالدخول (RFID, Biometric)
- مقاسم الهواتف (PBX, Trunk, Extension)
- تقنيات الشبكة الأساسية

---

### 2. واجهة المستخدم (`components/ai-chatbot.tsx`)

#### الميزات المتوفرة:
1. **رفع الصور**: زر إرفاق صورة 📎
2. **سجل المحادثات**: حفظ تلقائي مع عرض السجل السابق
3. **حذف المحادثات**: زر حذف لكل محادثة في السجل 🗑️
4. **الأسئلة المقترحة**: 6 أسئلة شائعة للبدء السريع
5. **حفظ المحادثات**: كل مستخدم له ID فريد ومحادثاته محفوظة في LocalStorage

#### التخزين:
- **التخزين المحلي**: LocalStorage
- **مفتاح التخزين**: `chat_messages_{userId}`
- **السجل**: آخر 10 محادثات سابقة

## 🧠 System Prompt (القواعد الصارمة)

```
أنت مساعد تعليمي متخصص في مادة "تكنولوجيا المباني الذكية" للصف الثاني عشر الصناعي.

قواعد صارمة:
1. أجب فقط على ما تعرفه بيقين من المنهاج الدراسي
2. إذا لم تكن متأكداً، قال "عذراً، لا أملك معلومات كافية للإجابة بدقة"
3. لا تختلق معلومات غير موجودة في الكتاب المدرسي
4. استخدم المصطلحات الفنية الصحيحة فقط
5. الإجابات قصيرة ودقيقة ومؤكدة
6. لا تجيب على أسئلة خارج المادة

المواضيع المسموح بها:
- CCTV (DVR, NVR, أنواع الكاميرات, BNC, RJ45)
- أنظمة إنذار الحريق (كواشف دخاني/حراري/لهبي, FACP, EOL)
- أنظمة إنذار السرقة (PIR, Magnetic Contact, Zones)
- التحكم بالدخول (RFID, Biometric, Fail-Safe/Secure)
- PBX (Trunk, Extension, IVR, MDF)
- PoE وشبكات CCTV الأساسية

لا تجيب عن: تاريخ، جغرافيا، رياضيات، علوم عامة، أسئلة شخصية.
```

## 🖼️ تحليل الصور

### الطريقة:
1. المستخدم يرفع صورة
2. الصورة تُحول لـ Base64
3. تُرسل مع السؤال للـ API
4. الـ AI يحلل أو يطلب وصف

### الـ Fallback:
إذا فشل Groq، يُرجع رداً يطلب وصف الصورة:
- كاميرا؟ حدد نوعها
- نظام إنذار؟ اشرح المكونات
- لوحة تحكم؟ أوضح الوظائف
