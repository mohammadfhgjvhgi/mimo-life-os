# Smart Parking + Safety System

## وصف المشروع

نظام ذكي لوقف السيارات مع نظام سلامة متكامل، مبن على Arduino Mega + WiFi R3. النظام يدير عملية دخول وخروج السيارات تلقائياً عبر بوابات بسيرفوات، مع كشف الغاز والاهتزاز لتحريك باب الطوارئ عند الخطر. يعرض كل المعلومات على شاشة LCD I2C مع عداد زمني.

## خريطة المنافذ (Pin Map)

```
=== الحساسات ===
D52  ← حساس الدخول (TCRT5000 DO)
D4   ← حساس الخروج (TCRT5000 DO)
A9   ← حساس الغاز MQ2 (AO - أنالوغ)
D41  ← حساس الغاز MQ2 (DO - رقمي)
A10  ← حساس الاهتزاز SW-420 (AO - أنالوغ)

=== السيرفوات ===
D53  ← سيرفو باب الدخول (90°)
D3   ← سيرفو باب الخروج (90°)
D11  ← سيرفو باب الطوارئ (180°)

=== المخرجات ===
D25  ← ريليه (Active HIGH)
D8   ← بازار

=== الشاشة ===
D20  ← SDA (I2C)
D21  ← SCL (I2C)
```

## التوصيلات التفصيلية

### شاشة LCD I2C
```
LCD VCC  → 5V
LCD GND  → GND
LCD SDA  → D20
LCD SCL  → D21
```

### حساسات TCRT5000 (الدخول والخروج)
```
VCC → 5V
GND → GND
AO  → لا شيء (غير مستخدم)
DO  → D52 (دخول) أو D4 (خروج)
```
- LOW = كشف سيارة
- HIGH = لا شي

### حساس MQ2 (غاز)
```
VCC → 5V
GND → GND
AO  → A9
DO  → D41
```
- AO: قراءة أنالوغ (EMA filter، عتبة 400)
- DO: تأكيد رقمي (لازم LOW مع AO عالي = &&)

### حساس SW-420 (اهتزاز)
```
VCC → 5V
GND → GND
AO  → A10
DO  → لا شيء (غير مستخدم - يعطي إنذارات كاذبة)
```
- نستخدم AO فقط مع EMA filter

### السيرفوات
```
VCC (أحمر)    → 5V
GND (بني)     → GND
Signal (برتقالي) → D53 / D3 / D11
```

### ريليه
```
VCC → 5V
GND → GND
IN  → D25
```
- Active HIGH (يعمل لما 5V على IN)

### بازار
```
+ → D8
- → GND
```

## آلية العمل

### 1. نظام الباركينغ

- السعة القصوى: 9 سيارات
- حساس الدخول (D52): لما يكتشف سيارة يفتح باب الدخول 90°، ينتظر 3 ثواني، يسكر
- حساس الخروج (D4): لما يكتشف سيارة يفتح باب الخروج 90°، ينتظر 3 ثواني، يسكر
- منع التكرار: 2 ثانية بين كل عملية
- حماية السيرفو: بعد 5 حركات راحة 10 ثواني
- حركة السيرفو: تدريجية (+2° كل 30ms)

### 2. نظام كشف الغاز

- قراءة أنالوغ من A9 مع EMA filter (alpha = 0.1)
- قراءة رقمية من D41 كتأكيد
- الشرط: `(smoothGas > 400) && (gasDO == LOW)` (الاثنين معاً)
- لازم ثبات 1 ثانية عشان يطلق إنذار
- عند الإنذار: يفتح الأبواب الثلاثة + ريليه ON + بازار 1500Hz مستمر
- لما يروح الغاز: يسكر الكل + ريليه OFF + بازار صامت

### 3. نظام كشف الاهتزاز (زلزال)

- قراءة AO من A10 مع EMA filter (alpha = 0.1)
- المستويات: Stable (<400) / Light (<600) / Warning (<800) / Danger (800+)
- لازم ثبات 1 ثانية على Danger عشان يطلق إنذار
- عند الإنذار: يفتح الأبواب الثلاثة + ريليه ON + بازار 1000Hz مستمر
- بعد 10 ثواني: يسكر الكل + ريليه OFF + بازار صامت
- فترة تهدئة: 5 ثواني ما بيتقبّل إنذار جديد

### 4. باب الطوارئ

- سيرفو 180° على D11
- يفتح فقط عند إنذار غاز أو زلزال
- يفتح تدريجياً: 0° → 180° (每 2° بـ 15ms)
- يسكر تدريجياً: 180° → 0° (كل 2° بـ 15ms)

### 5. الشاشة

```
الوضع العادي:
C:3/9 D:001 .
01:25:30 v F:6

إنذار غاز:
  !! GAS LEAK !!
Lv:450 EVACUATE!

إنذار زلزال:
 !! EARTHQUAKE !!
  EVACUATE NOW!

بانتظار سيارة:
  PARK FULL!
   Can't Enter

راحة السيرفوات:
 System Cooling
 Please wait...
```

| الرمز | المعنى |
|-------|--------|
| C:3/9 | 3 سيارات من 9 |
| D:001 | اليوم الأول |
| 01:25:30 | ساعة:دقيقة:ثانية |
| v | سهم متحرك (<v>^) |
| F:6 | 6 أماكن فارغة |
| . | يومض كل ثانية |

### 6. أوضاع البازار

| الحدث | التردد | النمط |
|--------|--------|-------|
| فتح باب دخول/خروج | 800Hz | 3 تنبيهات متقطعة |
| إغلاق باب دخول/خروج | 500Hz | 2 تنبيهات متقطعة |
| إنذار غاز | 1500Hz | مستمر |
| إنذار زلزال | 1000Hz | مستمر |

### 7. الريليه

| الحدث | الحالة |
|--------|--------|
| باب مفتوح (دخول/خروج) | ON |
| باب سكر | OFF |
| إنذار غاز | ON |
| إنذار زلزال | ON |
| انتهاء الخطر | OFF |

## سلوك النظام الكامل

### مخطط القرارات

```
START
  │
  ├─→ قراءة الغاز (A9 + D41)
  ├─→ قراءة الاهتزاز (A10)
  │
  ├─→ هل غاز أو زلزال؟
  │     ├─ نعم → فتح الأبواب الثلاثة + ريليه + بازار
  │     │        │
  │     │        ├─ غاز: لما يروح → سكر الكل
  │     │        └─ زلزال: بعد 10 ثواني → سكر الكل → تهدئة 5 ثواني
  │     │
  │     └─ لا → هل حساس دخول أو خروج؟
  │              ├─ دخول: فتح باب الدخول 90° → انتظر 3 ثواني → سكر
  │              └─ خروج: فتح باب الخروج 90° → انتظر 3 ثواني → سكر
  │
  └─→ تحديث الشاشة (anti-flicker)
```

### الجدول الزمني

| الحدث | البوابات | الريليه | البازار | الباركينغ |
|--------|----------|---------|---------|-----------|
| دخول سيارة | الدخول 90° | ON→OFF | بيپ×3 ثم بيپ×2 | عداد +1 |
| خروج سيارة | الخروج 90° | ON→OFF | بيپ×3 ثم بيپ×2 | عداد -1 |
| كشف غاز | الثلاثة | ON | 1500Hz مستمر | معطل |
| انتهاء غاز | الثلاثة تسكر | OFF | صامت | يعمل |
| كشف زلزال | الثلاثة | ON | 1000Hz مستمر | معطل |
| بعد 10 ثواني | الثلاثة تسكر | OFF | صامت | معطل |
| بعد 15 ثانية | - | - | - | يعمل |
| راحة سيرفو | - | - | - | معطل 10 ثواني |

## طريقة البرمجة (USB مكسور)

لأن USB الميجا مكسور، نستخدم Arduino Uno كمبرمج ICSP:

### التوصيل (ICSP)
```
Uno D13 → Mega D50 (SCK)
Uno D12 → Mega D51 (MISO)
Uno D11 → Mega D52 (MOSI)
Uno D10 → Mega RESET
Uno 5V  → Mega 5V
Uno GND → Mega GND
```

### خطوات الرفع
1. افتح ArduinoISP على Uno (مع `SPI_CLOCK` = `100000/6` للسرعة البطيئة)
2. اختر Board: Arduino Mega أو Mega ADK
3. اختر Programmer: Arduino as ISP
4. اضغط Upload Using Programmer (ليس Upload)

## ملاحظات تقنية

### لماذا نستخدم AO بدل DO لل الاهتزاز؟
DO يعتمد على مقارن LM393 اللي بيعطي HIGH/LOW بدون فلتر - بيتأثر من الضوضاء الكهربائية.
AO يعطي قيمة أنالوغ حقيقية (0-1023) نقدر نفلترها بـ EMA في الكود.

### لماذا نستخدم && وليس || للغاز؟
```
|| تعني: أنالوغ عالي أو رقمي LOW = إنذار (D41 يعطي LOW كاذب = مشكلة)
&& تعني: أنالوغ عالي ورقمي LOW = إنذار (الاثنين لازم يتفقوا = أمان)
```

### لماذا anti-flicker؟
كل `lcd.clear()` تسبب رمش على الشاشة. الـ `printLine` يكتب فقط لما النص يتغير.

### لماذا EMA filter؟
`smoothGas = smoothGas * 0.9 + raw * 0.1` يعني القراءة الحالية وزنها 10% فقط.
القراءات المفردة (الضوضاء) ما بتأثر كثير، بس القراءات المستمرة (غاز حقيقي) بترتفع تدريجياً.
