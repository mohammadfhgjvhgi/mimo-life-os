هاد ملخص كامل لكل قطعة مع المنفذ على لوحة Arduino Mega 2560:

## ⚡ القطع والمنافذ - Arduino Mega 2560

| # | القطعة | المنفذ | نوع الإشارة | الوظيفة |
|---|--------|--------|-------------|---------|
| 1 | **Servo SG90** - بوابة الدخول | **D9** | PWM (إشارة) | فتح/إغلاق البوابة (0°=مقفل، 90°=مفتوح) |
| 2 | **Servo SG90** - بوابة الخروج | **D10** | PWM (إشارة) | فتح/إغلاق البوابة |
| 3 | **Servo SG90** - باب غرفة الأمان | **D53** | PWM (إشارة) | فتح/إغلاق بالـ RFID |
| 4 | **IR Sensor FC-51** - دخول | **D27** | Digital INPUT_PULLUP | كشف سيارة واقفة عند البوابة (LOW=موجود) |
| 5 | **IR Sensor FC-51** - خروج | **D28** | Digital INPUT_PULLUP | كشف سيارة واقفة عند الخروج (LOW=موجود) |
| 6 | **DHT11** - حرارة/رطوبة | **D26** | Digital (بروتوكول خاص) | قراءة الحرارة والرطوبة |
| 7 | **MQ-2** - حساس غاز | **A0** | Analog INPUT (0-1023) | قراءة مستوى الغاز بالـ ppm |
| 8 | **Flame Sensor** - حساس لهب | **D22** | Digital INPUT_PULLUP | كشف الحريق (LOW=نار) |
| 9 | **SW-420** - حساس اهتزاز | **D23** | Digital INPUT_PULLUP | كشف الاهتزاز (HIGH=اهتزاز) |
| 10 | **Buzzer** - جرس إنذار | **D24** | Digital OUTPUT | صوت تنبيه عند الخطر |
| 11 | **Relay 1CH** - إضاءة | **D25** | Digital OUTPUT | تشغيل/إطفاء إنارة الكراج |
| 12 | **MFRC522 RFID** - بطاقات | **D8 (SS)** + **D49 (RST)** | SPI (D50=MISO, D51=MOSI, D52=SCK) | فتح باب الأمان ببطاقة معتمدة |
| 13 | **LCD 16x2 I2C** - شاشة | **SDA=A4, SCL=A5** | I2C | عرض عدد السيارات والحرارة |

## 🔌 ESP8266 - الاتصال مع Mega 2560

| ESP8266 | Mega 2560 | الوظيفة |
|---------|-----------|---------|
| **TX (D1/GPIO5)** | **RX (Serial1)** | ESP يرسل أوامر للمega |
| **RX (D2/GPIO4)** | **TX (Serial1)** | Mega يرسل بيانات للـ ESP |

> ملاحظة: بستخدموا **Serial1** على Mega (D18=TX1, D19=RX1) مش Serial الأساسي عشان ما يتعارض مع USB

## 🎬 السيناريوهات (كيف يشتغل النظام)

### سيناريو 1: دخول سيارة 🚗
```
1. سيارة تقرب من بوابة الدخول
2. IR Entry (D27) يكتشفها → يعطي LOW
3. لو الكراج ما ممتلئ (carsInside < 9):
   a. Servo الدخول (D9) يلف لـ 90° → البوابة تفتح
   b. السيارة تدخل
   c. IR Entry (D27) يرجع HIGH (السيارة عدت)
   d. Servo (D9) يرجع لـ 0° → البوابة تقفل
   e. carsInside++ → يرسل البيانات للـ ESP
4. لو الكراج ممتلئ:
   a. Buzzer (D24) يصفر مرتين → رفض
   b. البوابة تفضل مقفولة
```

### سيناريو 2: خروج سيارة 🚪
```
1. سيارة تقرب من بوابة الخروج
2. IR Exit (D28) يكتشفها → LOW
3. Servo الخروج (D10) يلف لـ 90° → تفتح
4. السيارة تخرج
5. IR Exit (D28) يرجع HIGH
6. Servo (D10) يرجع لـ 0° → تقفل
7. carsInside--
```

### سيناريو 3: إنذار غاز 💨
```
1. MQ-2 (A0) يقرأ قيمة
2. لو القيمة > 300 ppm:
   a. Buzzer (D24) يصفر 10 مرات
   b. Relay (D25) يشغل إنارة الطوارئ
   c. يرسل تنبيه للـ ESP → Firebase → الموقع
3. لو القيمة عادية → لا شي
```

### سيناريو 4: كشف حريق 🔥
```
1. Flame Sensor (D22) يقرأ LOW → فيه نار
2. نفس ردة فعل الغاز (Buzzer + إنارة)
3. يرسل تنبيه فوري
```

### سيناريو 5: RFID لغرفة الأمان 📇
```
1. حارس الأمن يقرب بطاقة RFID من MFRC522
2. الـ Arduino يقرأ رقم البطاقة
3. لو البطاقة معتمدة (في القائمة):
   a. Servo الأمان (D53) يفتح 90°
   b. يغلق تلقائياً بعد 5 ثواني
4. لو مو معتمدة:
   a. Buzzer يصفر 3 مرات (رفض)
```

### سيناريو 6: تحكم من الموقع 🌐
```
1. المستخدم يضغط "فتح بوابة الدخول" على الموقع
2. الموقع يكتب في Firebase: commands/entryGate = true
3. ESP8266 يقرأ الأمر من Firebase
4. ESP يرسل على Serial: "CMD:ENTRY:1"
5. Mega يستقبل الأمر من Serial
6. Servo (D9) يفتح البوابة
```

## 📡 نقل البيانات بين Mega و ESP

### Mega يرسل للـ ESP (كل 2 ثانية):
```
DATA:6,27.5,50,0,120,0,0,0
│   │  │   │  │  │  │  └─ IR Exit (0/1)
│   │  │   │  │  │  └──── IR Entry (0/1)
│   │  │   │  │  └─────── Vibration (0/1)
│   │  │   │  └────────── Gas Level (ppm)
│   │  │   └───────────── Flame (0/1)
│   │  └────────────────── Humidity
│   └───────────────────── Temperature
└──────────────────────── Cars Count
```

### ESP يرسل للمega (أوامر):
```
CMD:ENTRY:1      → فتح بوابة الدخول
CMD:ENTRY:0      → إغلاق بوابة الدخول
CMD:EXIT:1       → فتح بوابة الخروج
CMD:SECURITY:1   → فتح باب الأمان
CMD:LIGHT:1      → تشغيل الإضاءة
CMD:BUZZER:1     → تشغيل الجرس
```
