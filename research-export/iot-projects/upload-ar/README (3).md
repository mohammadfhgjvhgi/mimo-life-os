## 📋 الوصف

نظام كراج ذكي متكامل يتيح:
- **المراقبة الفورية** لعدد السيارات وحالة المستشعرات
- **التحكم عن بُعد** بالبوابات الثلاث
- **نظام إنذار** للغاز والاهتزاز مع فتح تلقائي لأبواب الطوارئ
- **حجز المواقف** إلكترونياً
- **تقارير وإحصائيات** شاملة
- **شاشة LCD** مع عداد زمني ومؤشرات

## 🔧 القطع المستخدمة

### المتحكمات
| القطعة | الكمية | الوصف |
|--------|--------|-------|
| Arduino Mega + WiFi R3 | 1 | المتحكم الرئيسي (ATmega2560 + ESP8266) |
| Arduino Uno | 1 | كمبرمج ICSP (USB الميجا مكسور) |

### المحركات (سيرفوات)
| القطعة | المنفذ | الزاوية | الوصف |
|--------|--------|---------|-------|
| Servo Motor | D53 | 0° ← 90° → 0° | بوابة الدخول |
| Servo Motor | D3 | 0° ← 90° → 0° | بوابة الخروج |
| Servo Motor | D11 | 0° ← 180° → 0° | باب الطوارئ |

### المستشعرات
| القطعة | المنفذ | الوصف | الحالة |
|--------|--------|-------|--------|
| TCRT5000 | D52 | كشف السيارات عند الدخول | ✅ شغال |
| TCRT5000 | D4 | كشف السيارات عند الخروج | ✅ شغال |
| MQ-2 Gas | A9 + D41 | كشف الغاز (AO + DO) | ✅ شغال |
| SW-420 Vibration | A10 | كشف الاهتزاز (AO فقط) | ✅ شغال |

### القطع المحذوفة
| القطعة | المنفذ | السبب |
|--------|--------|-------|
| حساس اللهب | A8 | يقرأ 1023 دائماً (معطل كهربائياً) |
| DHT11 | D22/D24 | القطعة ميتة |
| DS1302 RTC | - | معطل، نستخدم millis() بدله |
| IR Receiver | 30/22/9 | القطعة ميتة، استبدلنا بـ TCRT5000 |

### المكونات الأخرى
| القطعة | المنفذ | الوصف |
|--------|--------|-------|
| LCD I2C 20x4 | D20 (SDA) / D21 (SCL) | شاشة العرض |
| Relay NC | D25 | تحكم الحمل (Active HIGH) |
| Buzzer | D8 | تنبيه صوتي |

## 📱 مميزات التطبيق

### لوحة التحكم
- إحصائيات فورية (12 موقف، 8 مشغولة، 4 فارغة)
- حالة النظام (آمن / إنذار غاز / إنذار اهتزاز)
- رسوم بيانية حية
- سجل الأحداث
- مؤشر حالة الاتصال
- شريط تقدم الإشغال

### التحكم بالبوابات
- بوابة الدخول (D53 - 90°)
- بوابة الخروج (D3 - 90°)
- باب الطوارئ (D11 - 180°)
- رسوم متحركة للبوابات

### المستشعرات
- TCRT5000 للدخول والخروج
- MQ-2 للغاز (AO + DO مع منطق AND)
- SW-420 للاهتزاز (AO فقط مع EMA filter)
- Relay و Buzzer

### نظام الحجز
- 12 موقف
- حجز إلكتروني
- حساب الرسوم

### التقارير
- يومي / أسبوعي / شهري
- تصدير PDF / Excel

## 🔧 خريطة المنافذ (Pin Map)

```
=== الحساسات ===
D52  ← حساس الدخول (TCRT5000 DO)
D4   ← حساس الخروج (TCRT5000 DO)
A9   ← حساس الغاز MQ2 (AO)
D41  ← حساس الغاز MQ2 (DO)
A10  ← حساس الاهتزاز SW-420 (AO)

=== السيرفوات ===
D53  ← سيرفو باب الدخول (90°)
D3   ← سيرفو باب الخروج (90°)
D11  ← سيرفو باب الطوارئ (180°)

=== المخرجات ===
D25  ← ريليه (Active HIGH)
D8   ← بازار

=== الشاشة ===
D20  ← SDA (I2C)
D21  ← SCL (I2C)
```

## 🚀 طريقة البرمجة (USB مكسور)

### التوصيل (ICSP)
```
Uno D13 → Mega D50 (SCK)
Uno D12 → Mega D51 (MISO)
Uno D11 → Mega D52 (MOSI)
Uno D10 → Mega RESET
Uno 5V  → Mega 5V
Uno GND → Mega GND
```

### خطوات الرفع
1. افتح ArduinoISP على Uno (مع `SPI_CLOCK` = `100000/6`)
2. اختر Board: Arduino Mega 2560
3. اختر Programmer: Arduino as ISP
4. اضغط Upload Using Programmer
