## 1. Product Overview

Claude is Anthropic's AI assistant, accessible through chat interface and API, first announced March 14, 2023 [Source: https://www.anthropic.com/news/introducing-claude, accessed 2026-11-15]. As of the most recent model launch, the flagship is Claude Sonnet 4.5 (released Sep 29, 2025), described by Anthropic as "the best coding model in the world. It's the strongest model for building complex agents. It's the best model at using computers" [Source: https://www.anthropic.com/news/claude-sonnet-4-5, accessed 2026-11-15]. Earlier releases in the Claude 4 family — Claude Opus 4 and Claude Sonnet 4 — were announced May 22, 2025 [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15].

Per Anthropic's release notes (latest entry Aug 6, 2026), the model lineup as of Nov 2026 includes Claude Opus 5 (Jul 24, 2026), Claude Sonnet 5 (Jun 30, 2026), Claude Fable 5 / Mythos 5 (Jun 9, 2026, suspended Jun 12, restored Jul 1, 2026), Claude Haiku 4.5 (Oct 15, 2025) and Claude Opus 4.5 (Nov 24, 2025) [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15]. Claude Opus 4 and 4.1 were deprecated from Claude and Claude Code on Jan 16, 2026 [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

The product surface includes: the Claude web app (claude.ai / claude.com), Claude Desktop (macOS / Windows), Claude Mobile (iOS / Android), Claude Code (CLI + IDE extensions + Web), Claude API / Claude Developer Platform, Claude Cowork (agentic desktop product, GA April 9, 2026), Claude in Chrome (browser extension), Claude for Excel / PowerPoint / Word, and Claude Design (Anthropic Labs) [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15]. Plans: Free, Pro, Max, Team, Enterprise [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

## 2. Product Philosophy (Anthropic safety-first + Constitutional AI)

Anthropic positions itself as "an AI safety and research company that's working to build reliable, interpretable, and steerable AI systems" [Source: https://www.anthropic.com/news/introducing-claude, accessed 2026-11-15]. The launch announcement frames Claude as "based on Anthropic's research into training helpful, honest, and harmless AI systems" and emphasizes that Claude is "much less likely to produce harmful outputs, easier to converse with, and more steerable" [Source: https://www.anthropic.com/news/introducing-claude, accessed 2026-11-15].

Claude Sonnet 4.5 is explicitly described as "the most aligned frontier model we've ever released, showing large improvements across several areas of alignment" with reductions in "sycophancy, deception, power-seeking, and the tendency to encourage delusional thinking" [Source: https://www.anthropic.com/news/claude-sonnet-4-5, accessed 2026-11-15]. The model is released under "AI Safety Level 3 (ASL-3) protections" per Anthropic's Responsible Scaling Policy, which "matches model capabilities with appropriate safeguards" including classifiers that "aim to detect potentially dangerous inputs and outputs—in particular those related to chemical, biological, radiological, and nuclear (CBRN) weapons" [Source: https://www.anthropic.com/news/claude-sonnet-4-5, accessed 2026-11-15]. Claude 4 was likewise "shipped under ASL-3 protections" [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15].

The original Claude 4 announcement references "implementing measures for higher AI Safety Levels like ASL-3" and notes that both models are "65% less likely to engage in [shortcut or loophole] behavior than Sonnet 3.7 on agentic tasks that are particularly susceptible to shortcuts and loopholes" [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15]. Anthropic's safety-first philosophy is operationalized in product through explicit ASL gating, classifier-based input/output screening, and a documented willingness to suspend model access (e.g., Fable 5 / Mythos 5 were suspended Jun 12, 2026 and restored Jul 1, 2026) [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

The Sonnet 4.5 release describes Claude as a stateless chat interface transformed into "a knowledgeable collaborator that builds understanding over time" via memory [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. ## 4. User Journey

A new Claude user signs up at claude.ai (region-locked — direct curl from this sandbox returns HTTP 200 → `https://claude.com/app-unavailable-in-region` [Observed: local curl with Chrome UA, accessed 2026-11-15]). Onboarding is minimal: the empty state presents a single chat input plus prompt seeds organized by use mode (Write / Learn / Code) [Source: https://www.anthropic.com/claude, accessed 2026-11-15].

The user then has the option to: (a) start an incognito chat via the ghost icon in the upper right corner [Source: https://support.claude.com/en/articles/12260368-use-incognito-chats, accessed 2026-11-15]; (b) start a regular chat that contributes to Memory; (c) create or open a Project (free users capped at 5 projects; paid users unlimited) [Source: https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features, accessed 2026-11-15]; (d) open the Artifacts section in the sidebar to view previously published artifacts or create new ones [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15]; or (e) on Max/Pro plans, dispatch Cowork sessions [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

Memory is on by default for free, Pro, and Max plans (rolled out to free users March 2, 2026); users can Pause or Reset memory at any time from Settings > Memory [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. The user journey is intentionally stateful: every non-incognito chat contributes to memory entries that are visible, editable, and exportable [Source: https://support.claude.com/en/articles/12123587-import-and-export-your-memory-from-claude, accessed 2026-11-15].

## 5. Navigation (sidebar, Projects)

The Claude sidebar exposes: chats (with chat history search), Projects, and Artifacts as distinct sections [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15]. The user's initials / name in the lower left corner is the global entry point to Settings, which itself contains Account, Capabilities, Memory (new experience) or Capabilities > Memory (legacy), Reflect (monthly recap), and Time and focus (break reminders / quiet hours) [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15; Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].

Projects are "self-contained workspaces with their own chat histories and knowledge bases. Within each project, you can upload documents, provide context, and have focused chats with Claude" [Source: https://support.claude.com/en/articles/what-are-projects, accessed 2026-11-15 — cached locally as `curl_support_features.clean.txt`]. Each project has its own memory space and dedicated project summary, isolated from other projects and non-project chats [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. Team / Enterprise plans add a "Shared with me" tab, email notifications on shares, and three permission levels (Can view / Can edit / Project creator) [Source: https://support.claude.com/en/articles/what-are-projects, accessed 2026-11-15].

As of July 7, 2026, "Chat and Cowork share one home now, with one place for your projects and artifacts across both" [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

## 6. Workspace (Artifacts side panel)

When Claude creates an artifact, "you'll see the content displayed in a dedicated window to the right of the main chat" [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15]. The side panel supports multiple artifacts in a single conversation; a slider icon in the upper right lets the user switch between them and select which artifact Claude should reference for updates [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15].

In the lower right corner of the artifact window, the user can: view underlying code, copy content (including code), download files, and publish / share [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15; Source: https://support.claude.com/en/articles/10012583-publish-and-share-artifacts, accessed 2026-11-15]. Version selector allows switching between versions; editing prior chat messages creates a "different version of the conversation, with its own set of artifacts" [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15]. Since June 12, 2026, Markdown drafts can be edited in place: "Highlight the part you want changed, type the change, and Claude makes the edit right where you marked it" [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15; Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15].

The Artifacts section in the sidebar is the workspace for managing published artifacts: view all creations, create new ones from scratch, manage and organize the collection. Artifacts created in a conversation don't appear in the sidebar automatically — the user must click "Publish" to add them [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15].

## 7. Conversation (streaming)

Claude conversations are streaming — token-by-token text rendering is the default mode for all models. The Claude 4 family are "hybrid models offering two modes: near-instant responses and extended thinking for deeper reasoning" [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15]. Extended thinking with tool use (beta) lets Claude "alternate between reasoning and tool use to improve responses" — including web search during reasoning [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15]. Claude 4 also introduced "thinking summaries" produced by a smaller model that condense lengthy thought processes — needed about 5% of the time; "Developer Mode" (contact sales) retains raw chains of thought [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15].

When Claude references previous conversations via Memory or chat search, "you'll see citations linking back to the original chats, along with the option to delete specific conversations" [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. Chat search itself appears as a tool call in the current chat [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. Context window compaction (Nov 24, 2025) enables "infinite-length conversations (with some exceptions) and significantly reduce length limit errors by summarizing earlier messages when a chat approaches its context limit" [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15]. Sonnet 4.6 (Feb 17, 2026) added a 1M token context window in beta [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

Interactive inputs (multiple choice, multi-select, ranking) sometimes appear "at the bottom of the chat" before Claude responds; the user can still type a response [Source: https://support.claude.com/en/articles/13641943-visual-and-interactive-content, accessed 2026-11-15].

Claude 3.5 Sonnet is the first frontier AI model to offer computer use in public beta" [Source: https://www.anthropic.com/news/3-5-models-and-computer-use, accessed 2026-11-15]. Sonnet 4.5 reaches 61.4% on OSWorld, up from 42.2% on Sonnet 4 [Source: https://www.anthropic.com/news/claude-sonnet-4-5, accessed 2026-11-15].

The extension can "read console errors, network requests, and DOM state to help debug issues directly," record workflows by user demonstration, and work across multiple browser tabs [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].
- **Claude Cowork**: agentic desktop product that "runs locally on your computer in an isolated VM, enabling direct access to local files and MCP integrations" [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15]. ## 9. Memory (context-only — NO; persistent memory NOW EXISTS — verify)

**Critical correction to the prompt's premise:** Claude now HAS persistent memory. The prompt's hypothesis ("no persistent memory — verify current state") reflects a pre-September 2025 state. The current state, as of November 2026, is:

Memory was first introduced to Claude on September 11, 2025 (Team plans + incognito chats for Free/Pro/Max/Team), extended to Enterprise on September 18, 2025, to Max on October 23, 2025, to Pro on October 23, 2025 (gradual rollout), and to Free on March 2, 2026 [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

On July 10, 2026, Anthropic shipped a major memory update: "Memory on Claude now works as a set of individual, categorized entries that Claude reads and updates during your conversations, replacing the previous daily memory summary" [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15]. The new experience lives at `Settings > Memory`; the legacy experience lived at `Settings > Capabilities > Memory` [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].

**Memory capabilities (current state):**
- Claude reads, writes, and updates memory entries "in real time as you chat rather than on a fixed daily schedule" [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].
- Memory entries are organized into categories (role, projects, professional context; communication preferences and working style; technical preferences and coding style; project details and ongoing work) [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].
- Each project has its own separate memory space and dedicated project summary, isolated from other projects and non-project chats [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].
- Users can view, edit, and delete individual entries from `Settings > Memory` or directly from chat ("tell Claude what you'd like it to remember") [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].
- Two disable modes: **Pause memory** (keeps existing memory, stops making new ones) and **Reset memory** (permanently deletes all memories including project memories) [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].
- Memory can be imported from / exported to other AI providers (experimental) [Source: https://support.claude.com/en/articles/12123587-import-and-export-your-memory-from-claude, accessed 2026-11-15].
- Memory data is included in standard data exports and follows existing chat retention policies [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].

**Monthly recap (July 9, 2026):** Settings > Reflect shows topics spent time on, most active day and peak hour, and observations about how the user works with Claude. Requires memory to be on. Free/Pro/Max on web and Claude Desktop, in beta [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15]. Alongside it, `Settings > Time and focus` lets users set optional break reminders and quiet hours [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

**Legacy memory experience (still active for Team and Enterprise during rollout):** Memory synthesis updated every 24 hours; provided context for every new standalone conversation [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].

## 10. Knowledge (Projects knowledge)

Projects have an explicit knowledge base: "A key benefit of projects is the ability to provide context for your chats with Claude. You can upload relevant documents, text, code, or other files to a project's knowledge base, which Claude will use to better understand the context and background for your individual chats within that project" [Source: https://support.claude.com/en/articles/what-are-projects, accessed 2026-11-15]. Each project includes a 200K context window (the equivalent of a 500-page book) at launch (Jun 25, 2024) [Source: https://www.anthropic.com/news/projects, accessed 2026-11-15].

**Enhanced project knowledge with RAG** (paid plans Pro/Max/Team/Enterprise): "When your project knowledge approaches context limits, Claude seamlessly enables RAG mode to expand capacity by up to 10x while maintaining response quality" [Source: https://support.claude.com/en/articles/what-are-projects, accessed 2026-11-15]. Project knowledge is searchable via chat search — but only within the specific project boundary [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].

**Project instructions** (custom instructions per project): tailor Claude's responses — e.g., formal tone, perspective of a specific role or industry [Source: https://support.claude.com/en/articles/what-are-projects, accessed 2026-11-15; Source: https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features, accessed 2026-11-15].

**Profile-level instructions** (account-wide, distinct from project instructions): "Any instructions you add here will be applied to all of your conversations with Claude" [Source: https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features, accessed 2026-11-15]. Free users can create a maximum of five projects [Source: https://support.claude.com/en/articles/what-are-projects, accessed 2026-11-15; Source: https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features, accessed 2026-11-15].

## 11. Search

Two distinct search surfaces:

1. **In-chat Claude search** (paid plans Pro/Max/Team/Enterprise, on web/Desktop/Mobile): "You can prompt Claude to search through your previous conversations to find relevant information across sessions and reference specific details when needed... These searches use Retrieval-Augmented Generation (RAG) and will appear as tool calls during your conversations" [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. Searches are bounded: "All chats outside of projects" or "Individual project conversations (searches are limited to within each specific project)" [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. Toggleable from `Settings > Memory` ("Search and reference chats" toggle) [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].
2. **Web search** (separate capability): when enabled, powers data widgets like weather and recipes [Source: https://support.claude.com/en/articles/13641943-visual-and-interactive-content, accessed 2026-11-15]. Used internally by Claude Code during extended thinking [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15].

Incognito chats are excluded from search: "Claude won't pull information from incognito chats when searching previous conversations" [Source: https://support.claude.com/en/articles/12260368-use-incognito-chats, accessed 2026-11-15]. When Claude references a previous conversation via search, citations link back to the original chats with an option to delete specific conversations [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. Chat search cannot operate when an Enterprise org uses customer-managed encryption keys because conversation content is encrypted [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].

## 12. Execution (tool use, computer use)

Claude's execution surfaces are layered:

- **Tool use in chat**: Claude can use tools in parallel (Claude 4 capability), follow instructions more precisely, and "when given access to local files by developers—demonstrate significantly improved memory capabilities, extracting and saving key facts to maintain continuity" [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15].
- **Code Execution Tool** (API beta, with Claude 4 launch May 22, 2025): one of four new API capabilities announced alongside Claude 4 — code execution tool, MCP connector, Files API, and the ability to cache prompts for up to one hour [Source: https://www.anthropic.com/news/claude-4, accessed 2026-11-15].
- **In-app code execution** (Sep 9, 2025 — Sep 29, 2025 with Sonnet 4.5): "In the Claude apps, we've brought code execution and file creation (spreadsheets, slides, and documents) directly into the conversation" [Source: https://www.anthropic.com/news/claude-sonnet-4-5, accessed 2026-11-15; Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15]. Available on all paid plans [Source: https://www.anthropic.com/news/claude-sonnet-4-5, accessed 2026-11-15].
- **Computer Use** (API, Oct 22, 2024): Claude perceives and interacts with computer interfaces — looks at screen, moves cursor, clicks, types [Source: https://www.anthropic.com/news/3-5-models-and-computer-use, accessed 2026-11-15].
- **MCP connectors**: artifacts can connect to external services via Model Context Protocol (Asana, Google Calendar, Slack, custom MCP servers) [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15]. On Claude for Excel and PowerPoint, add-ins can now share full context across applications and connect via an LLM gateway [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].
- **Microsoft 365 connector** (write tools, Jul 7, 2026): Claude can draft, send, organize email; manage calendar events; update mailbox settings; create/update files in OneDrive and SharePoint. Teams remains read-only [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].

**Sandbox architecture for code execution in claude.ai**: Per Anthropic's engineering blog (May 25, 2026), "When Claude runs code inside claude.ai, it does so in a **gVisor container on isolated infrastructure**. The agent is entirely server-side; no code runs on the local machine, and the filesystem is ephemeral (per-session). The blast radius is minimal, but so is the ceiling on what Claude can do—there's no persistent workspace and no access to the user's filesystem" [Source: https://www.anthropic.com/engineering/how-we-contain-claude, accessed 2026-11-15]. The blog explicitly distinguishes three containment patterns: ephemeral container (claude.ai code execution, gVisor), HITL sandbox (Claude Code), and sealed VM (Claude Cowork) [Source: https://www.anthropic.com/engineering/how-we-contain-claude, accessed 2026-11-15].

## 13. Artifacts (DEEP VERIFY — CSP sandbox + Pyodide; share URL; types)

**Definition and triggering.** Claude creates an artifact when the content it's sharing: (1) is significant and self-contained (typically over 15 lines); (2) is something the user is likely to want to edit, iterate on, or reuse outside the conversation; (3) is complex content that stands on its own without requiring extra conversation context; (4) is content the user is likely to want to refer back to or use later [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15].

**Supported artifact content types** (per help center): Documents (Markdown or plain text), Code snippets, Single-page HTML websites, SVG images, Diagrams and flowcharts, Interactive React components [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15]. The "Visual and interactive content" help article separately notes that Claude can build "custom visuals" — diagrams, charts, interactive elements — directly in the conversation (beta, web/desktop only); these are distinct from artifacts proper [Source: https://support.claude.com/en/articles/13641943-visual-and-interactive-content, accessed 2026-11-15].

**Enabling artifacts.** "We no longer support artifacts without Code execution and file creation enabled in Settings > Capabilities (Free, Pro, Max) or Organization settings > Capabilities (Team, Enterprise)" [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15]. So as of late 2025/2026, artifacts REQUIRE Code execution + file creation to be on.

**Sandbox / runtime architecture — DEEP VERIFY.**

The prompt's hypothesis of "CSP sandbox + Pyodide" is only partially supported by available evidence, and the dominant execution path has shifted server-side:

1. **In-app Code Execution (server-side, gVisor)** — used for Python execution and file creation: "When Claude runs code inside claude.ai, it does so in a gVisor container on isolated infrastructure. The agent is entirely server-side; no code runs on the local machine, and the filesystem is ephemeral (per-session)" [Source: https://www.anthropic.com/engineering/how-we-contain-claude, accessed 2026-11-15]. This is the runtime that backs the "Code execution and file creation" capability introduced to the Claude apps with Sonnet 4.5 [Source: https://www.anthropic.com/news/claude-sonnet-4-5, accessed 2026-11-15]. Skills require the Code Execution Tool beta "which provides the secure environment they need to run" [Source: https://www.anthropic.com/news/skills, accessed 2026-11-15; Source: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills, accessed 2026-11-15]. **No primary-source evidence of Pyodide in the current Claude architecture was found** in any of: anthropic.com/news, anthropic.com/engineering, or support.claude.com help center articles retrieved on 2026-11-15. (Pyodide was historically used by Claude artifacts to run Python in the browser via WebAssembly; current docs route Python execution through the server-side Code Execution Tool / gVisor container instead. Cannot be confirmed or refuted from canonical docs alone — flagged as a known gap.)

2. **Client-side artifact rendering (sandboxed iframe)** — for React/HTML/SVG/Mermaid artifacts displayed in the side panel: the Anthropic marketing page at `https://www.anthropic.com/claude` embeds published artifacts via `<iframe src="https://claude.site/public/artifacts/<UUID>/embed?embed=true" title="" loading="lazy" class="artifact_iframe">` [Observed: HTML source of https://www.anthropic.com/claude, accessed 2026-11-15 — `<iframe src="https://claude.site/public/artifacts/068e2faa-dafe-4c15-82ff-b60f7dff7068/embed?embed=true" ...>` and `<iframe src="https://claude.site/public/artifacts/9ee841ee-4e30-4769-b2b8-8d9b6c48de24/embed?embed=true" ...>`]. The presence of a dedicated iframe per artifact strongly implies sandboxed rendering with restrictive Content-Security-Policy on the `claude.site` origin, but **no primary-source documentation explicitly states the CSP headers** applied to `claude.site` — flagged as a known gap (cannot directly fetch `claude.site` headers from this sandbox because the origin returns `https://claude.com/app-unavailable-in-region` HTTP 200 redirect from this region [Observed: local curl with Chrome UA to `https://claude.site/artifacts/test-uuid`, accessed 2026-11-15]).

**Share URL format — VERIFIED.** The prompt's hypothesis of `claude.site/artifacts/<uuid>` is close but slightly off. The actual verified pattern is:

```
https://claude.site/public/artifacts/<UUID>            (canonical public URL)
https://claude.site/public/artifacts/<UUID>/embed?embed=true   (iframe embed variant)
```

with `<UUID>` being a standard lowercase UUID v4 (e.g., `068e2faa-dafe-4c15-82ff-b60f7dff7068`, `9ee841ee-4e30-4769-b2b8-8d9b6c48de24`) [Observed: HTML source of https://www.anthropic.com/claude, accessed 2026-11-15]. **Publishing vs. sharing.** "Publishing (Free, Pro, Max): Makes your artifact publicly available. Anyone with the link can view and interact with it." vs. "Sharing (Team, Enterprise): Makes your artifact available within your organization only. ## 18. Progressive Disclosure

Progressive disclosure is a core design principle across multiple Claude surfaces:

- **Memory**: by default, Claude reads/writes memory silently; the user sees entries only when navigating to `Settings > Memory`. Citations to past chats appear inline only when Claude references them [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].
- **Project instructions vs. profile instructions vs. skills**: layered — profile instructions apply globally; project instructions apply only within the project; skills add specific behaviors on demand [Source: https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features, accessed 2026-11-15].
- **Agent Skills**: explicitly designed around progressive disclosure — "At startup, the agent pre-loads the name and description of every installed skill into its system prompt. This metadata is the first level of progressive disclosure: it provides just enough information for Claude to know when each skill should be used without loading all of it into context. The actual body of this file is the second level of detail." Additional bundled files are a "third level (and beyond) of detail, which Claude can choose to navigate and discover only as needed" [Source: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills, accessed 2026-11-15].
- **Artifacts**: content >15 lines that is "likely to want to edit, iterate on, or reuse" is hoisted into a side panel rather than left inline; multiple versions are hidden behind a version selector [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15].
- **Beta / research preview labels**: features are explicitly tagged by maturity (beta vs. research preview) so users know which features are still evolving [Source: https://support.claude.com/en/articles/14503520-available-beta-and-research-preview-features, accessed 2026-11-15].

## 28. What should MiMo learn? (evidence-based)

1. **Per-project memory isolation with a per-project summary** — Claude's design where "each project has its own separate memory space and dedicated project summary, so the context within each of your projects is focused, relevant, and separate from other projects or non-project chats" [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. This is the right unit of memory segmentation for a knowledge-work product.

2. **Real-time memory writes with explicit Pause/Reset controls** — Claude moved away from a daily-summary model to per-entry real-time writes (Jul 10, 2026) [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15]. The two disable modes (Pause keeps existing memory; Reset permanently deletes) give users graduated control rather than a binary on/off [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15].

3. **Memory visible/editable from chat** — "tell Claude what you'd like it to remember, and it will update Claude's memory of you without needing to leave the conversation. Any edits made in this way will immediately apply to your next conversation" [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. No context switch for memory management.

4. **Past-chat citations with delete-option** — when Claude references a prior chat, the citation links back to the original chat and offers one-click deletion [Source: https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context, accessed 2026-11-15]. 6. **Edit-in-place for Markdown drafts** — "Highlight the text you want changed, click 'Edit with Claude,' and type your request. Removes the "describe which paragraph" tax.

7. **Multiple artifacts in one conversation with a slider switcher** — keeps parallel work visible without losing state [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15].

8. **"Try fixing with Claude" button on artifact errors** — converts an error into a one-click remediation, copying error details into a new message [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15].

Usage counts against each user's own Claude subscription limits, not yours" [Source: https://support.claude.com/en/articles/9796387-what-are-artifacts, accessed 2026-11-15]. Build once, use across apps / Code / API [Source: https://www.anthropic.com/news/skills, accessed 2026-11-15].

Not every feature graduates [Source: https://support.claude.com/en/articles/14503520-available-beta-and-research-preview-features, accessed 2026-11-15].

13. **Context window compaction** as a perceived-performance mechanism — silently summarize earlier messages to avoid length-limit errors [Source: https://support.claude.com/en/articles/release-notes, accessed 2026-11-15].
